VerdictBench: Can World Models Tell When a Policy Will Fail?

A benchmark that tests whether a world model's success verdict can be trusted for an individual run. VerdictBench pairs each imagined verdict with the simulator outcome of the same run from the same initial state, under graded shifts in layout, dynamics, and sensing annotated by whether each shift is visible to the model. We find that verdicts accept nearly every run even when many accepted plans fail, and that closed-loop replanning can hide these errors.

Sep 2026 to present, Research Assistant, University of Washington, supervised by Dr. Luyao Niu.

Tracking Asking Cost over Time: Learning When to Ask Each User in Embodied Agents

A lightweight reward-learning framework that lets a robot learn, for each user, when asking for clarification is worth the interruption. TACT estimates the utility of asking or acting from user context and interaction feedback, and replaces a fixed interruption cost with a learned, user-specific one. It updates passively from ordinary interaction and needs only a small amount of data and computation.

Jan 2026 to present, lead researcher, with early-stage input from Fan Zhang.

Algorithm Structure for Real-time General Game Playing Agents

General Game Playing studies AI agents that play unfamiliar games by reading only the rules at runtime, with no human intervention. Prior work has focused on turn-based games using generic heuristics or Monte Carlo/UCT search, but real-time games now dominate the market. This paper evaluates whether existing GGP algorithms can be adapted to real-time play and proposes a dual-server (strategy + acting) architecture to close the gap.

2022, independent research. My contribution: Sole author. Conducted the literature review and proposed the dual-server architecture, improving breadth and efficiency to better mimic human performance.
