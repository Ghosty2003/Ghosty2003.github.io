Projects & Research

Automated Workstation Reset — Bimanual Robot Tool Sorting

Bimanual SO-101 system that detects loose tools with YOLOv8m + RealSense and returns them to designated bins, automating the "Sort" step of industrial 5S. MoveIt IK planning paired with per-arm ACT-trained grasp policies. (Spring 2026, UW TECHIN 517)

BuddyBot — Intelligent Delivery Robot

ROS2-based human-following robot on Turtlebot3 using YOLO + MediaPipe for real-time tracking and gesture-driven FSM control. Features visual servoing, auto-recovery, and an adaptive lifting platform.

MuSHR — Full-Stack Autonomous Navigation

Full-stack self-driving system on NVIDIA Jetson Orin + ROS. Implements particle-filter localization (LiDAR + odometry), Halton-sampled roadmap with Lazy A*, Dubins Path planning, and MPC real-time control.

AquaCal — Intelligent Auto-Watering System

Integrated auto-watering system that turns plant care into an effortless experience: a visible watering calendar, sensor-driven optimal hydration, and remote app control. The entire vase is 3D-printed, wrapped in a custom-molded silicone skin for waterproofing.

The Devour — Hardware-Integrated Game

CircuitPython survival game on ESP32 integrating accelerometer motion control, rotary encoder input, OLED display, NeoPixel LEDs, buzzer feedback, persistent high-score storage, and a custom 3D-printed enclosure.

AV-Phys Bench: A Benchmark for Physical Commonsense in Joint Audio-Video Generation

AV-Phys Bench evaluates whether joint audio-video generation models understand real-world physics, rather than just producing plausible-looking sounds and frames. It tests seven models across Steady State, Event Transition, and Environment Transition scenes on five dimensions of semantic and physical commonsense. (arXiv:2605.07061)

My contribution: Helped design the benchmark's evaluation categories and rubrics, and led data collection and annotation verification across the three scene categories.

Algorithm Structure for Real-time General Game Playing Agents

General Game Playing studies AI agents that play unfamiliar games by reading only the rules at runtime, with no human intervention. Prior work has focused on turn-based games using generic heuristics or Monte Carlo/UCT search, but real-time games now dominate the market. This paper evaluates whether existing GGP algorithms can be adapted to real-time play and proposes a dual-server (strategy + acting) architecture to close the gap.

My contribution: Sole author. Conducted the literature review and proposed the dual-server architecture, improving breadth and efficiency to better mimic human performance.

Long-tail Bias Mitigation in HOI Detection

Training framework on QPIC Transformer for Human-Object Interaction detection. ATL-inspired parameter enhancement + pseudo-labeling boosted mAP by 1.6% and tail-class accuracy by 5.1%–6.3% on V-COCO. (Dec. 2024–May 2025, Tongji)

Exploring Joyhack in Games Using AI NPCs

User study on how players tamper with AI NPCs using observational methods and semi-structured interviews on the "Suck Up" game. Analyzed player expectations to guide future AI NPC research. (Jan.–Sept. 2024, UC Berkeley)
